# Begriffserklärung
**[[8-bit AVR]]** ist eine Mikrocontroller-Architektur von Atmel (heute Microchip Technology).
# Begriffs Herleitung
- Die Architektur verwendet einen **8** Bit breiten Hauptdatenpfad.
- **AVR** Wsteht für "**A**lf and **V**egard’s **R**ISC processor**"

Die Architektur basiert auf einem RISC-Prinzip (Reduced Instruction Set Computing), ist effizient, leicht programmierbar und kommt häufig in Embedded-Systemen wie Arduino-Boards zum Einsatz. Typische Merkmale sind die Harvard-Architektur (eigener Speicher für Programm und Daten), Flash- und EEPROM-Speicher sowie eine schnelle Ausführung einfacher Maschinenbefehle.
