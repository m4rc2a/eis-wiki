# Begriffserklärung
**[[VDE 0702]]** ist eine **DIN Norm**, welche das Vorgehen bei einer Wiederholungsprüfung für elektrische Geräte beschreibt.
Ehemals [[VDE 0701-0702|VDE 701-702]] genannt.
