Eine [[Summe Störung]] bezeichnet eine Sammelmeldung, die immer dann aktiviert wird, wenn irgendwo innerhalb einer definierten Gruppe von überwachten Geräten, [[Sensoren]] oder Prozessen eine Störung auftritt.  
Statt jede Einzelstörung separat zu melden, wird mit einer „Summenanzeige“ angezeigt, **dass generell irgendwo eine Störung existiert** – ohne den exakten Ort sofort zu nennen. Eine Summe Störungs Anzeige kann z. B. durch eine LED oder einen Alarm erfolgen.
