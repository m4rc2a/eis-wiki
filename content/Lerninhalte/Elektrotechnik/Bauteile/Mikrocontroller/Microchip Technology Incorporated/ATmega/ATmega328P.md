Der **[[ATmega328P]]** ist ein [[Mikrocontroller]] aus der AVR-Familie von **[[Microchip Technology Incorporated|Microchip Technology]]** (früher Atmel).
Er ist besonders bekannt, weil er im **Arduino Uno** Board verwendet wird.
# Eigenschaften

| Parameter            | Wert               |
| -------------------- | ------------------ |
| **[[CPU Architekturen|CPU Architektur]]**  | [[8-bit AVR]]      |
| **Maximum CPU Takt** | $20\,\mathrm{MHz}$ |
| **Flash Speicher**   | $32\,\mathrm{KB}$  |
| **SRAM**             | $2\,\mathrm{KB}$   |
| **EEPROM**           | $1\,\mathrm{KB}$   |
| **Maximum I/O**      | 23                 |
