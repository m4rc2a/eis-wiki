# Begriffserklärung
Der **AT89S405** ist ein [[Mikrocontroller]] aus der [[AT89]] Serie von Microchip. Aus dem Grund ist der **AT89S405** kompatibel zum [[Intel 8051]].
# Eigenschaften

| Parameter            | Wert                  |
| -------------------- | --------------------- |
| **CPU Typ**          | 8-Bit 8051-kompatibel |
| **Maximum CPU Takt** | $24\,\mathrm{MHz}$    |
| **Flash Speicher**   | $8\,\mathrm{KB}$      |
| **SRAM**             | $256\,\mathrm{Byte}$  |
| **EEPROM**           | $0\,\mathrm{KB}$      |
| **Maximum I/O**      | 32                    |
